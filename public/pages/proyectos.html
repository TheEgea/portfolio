Ethical Pentesting Lab

2025 — Present

View website →

Design, implementation and documentation of four offensive/defensive cybersecurity labs built on EVE-NG and deployed on Proxmox. Each lab simulates a real-world scenario with a full network topology (pfSense, VyOS, Ubuntu Server/Desktop).

LAB 1
Reconnaissance & Enumeration

Network scanning, service enumeration and traffic analysis with Wireshark. pfSense and VyOS configured from scratch.

LAB 2
Web Vulnerabilities

Exploitation of XSS, SQL Injection and Command Injection on a purposely vulnerable Flask app deployed in the lab.

LAB 3
Incident Response & Forensics

Log analysis, IOC detection and attack timeline reconstruction. Privilege escalation via sudo/find.

LAB 4
CipherStrike — Ransomware

Ransomware attack simulation: initial infection, file encryption, lateral movement and defensive analysis.
